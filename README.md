# top-IMDb-movies-in-2026-data-analyst
## project overview
Project: IMDb Top 250 Movies Data Analysis
Dataset: Top 250 Movies on IMDb in 2026
Tools: Python, Pandas, Jupyter Notebook, Microsoft Power BI
Analysis Type: Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization

## project description
Proyek ini merupakan analisis terhadap dataset 250 film yang masuk dalam daftar IMDb Top 250. Analisis dilakukan untuk memahami karakteristik film berdasarkan rating IMDb, genre, tahun rilis, dan jumlah vote

Proyek ini dibuat sebagai latihan penerapan proses kerja Data Analyst, mulai dari memahami data, melakukan data cleaning, melakukan eksplorasi data, membuat visualisasi, hingga menarik kesimpulan berdasarkan hasil analisis.

## problem statement
1. Genre apa yang paling banyak muncul dalam IMDb Top 250?
2. Periode tahun berapa yang memiliki jumlah film terbanyak?
3. Apakah terdapat hubungan antara IMDb Rating dan Metacritic Score?
4. Apakah jumlah vote berhubungan dengan rating film?

## dataset
dataset = top 250 movies on IMDb in 2026 
source = https://www.kaggle.com/datasets/arjunsinghgangwar/top-250-movies-on-imdb-in-2026
